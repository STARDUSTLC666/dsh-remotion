# 0.9.0 图片排序验收

2026-10-28，Windows / Node 24.16 / 官方 DSH 0.2.1-rc.3 Web，后台 Chrome / Playwright。Browser plugin 不可用，因此采用本地 Playwright，不切换用户前台窗口。

- 实际创建轮播工程，上传三张有效 PNG，用鼠标和键盘调整顺序，关闭详情再打开验证持久化。
- 真正准备官方渲染环境并导出 6 秒 MP4，下载后在 1/3/5 秒抽帧，逐张查看确认绿色、蓝色、红色顺序；再次移动图片后旧 MP4 的 SHA-256 保持一致，界面提示重新导出。
- 中文浅色、英文深色及 390px 窄屏实际操作；窄屏按钮也实际点击，图片重新排列成功；未捕获页面异常。
- 后端覆盖图片完整排列、重复/缺失/外来 ID、旧修订、空操作、混合音频位置、文件字节和旧渲染记录保留。

Remotion 保持官方 4.0.539 的当前技能与固定渲染器。

未测：Electron 专属菜单、全部模板/格式组合、所有外部媒体与真实业务项目。受控测试素材不代表任意用户项目。自动安装继续默认关闭。
